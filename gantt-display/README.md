# Affichage Gantt

Permet d'afficher un diagramme de Gantt avc un découpage par mois et semaines ISO.

<img width="1746" height="629" alt="2026-08-21 10_06_52-Gantt - Grist Eurométropole — Mozilla Firefox" src="https://github.com/user-attachments/assets/bd488bfd-9f00-433a-a39f-94c25d0b9e0d" />

Note : Ce widget sert uniquement à de la visualisation. Il est volontairement simple et a pour objectif de le rester. D'autres widgets de Gantt plus approfondis existent pour aller plus loin. 

## Configuration 

Il y a 4 colonnes à paramétrer :
* **Titre** : type Texte
* **Activité** : _sans type défini_
* **Date de début** : type Date
* **Date de fin** : type Date

Par défaut le diagramme s'affiche à partir de la date du jour sur une période de 3 mois. Il est possible de modifier la période en utilisant les sélecteurs de date.

### Impression

Pour pouvoir imprimer le diagramme avec les couleurs, il faut cocher la case "Imprimer les arrières-plans" dans le panneau de configuration d'impression.
